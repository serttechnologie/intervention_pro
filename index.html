💾 Changer le Stockage Interne

Si vous voulez changer de dossier racine, basculer sur une carte SD, ou si vous avez des erreurs d'accès, cliquez sur le bouton ci-dessous pour modifier l'emplacement cible.

📂 Où sont mes fichiers ?

Ils sont sur votre téléphone dans le dossier que vous avez autorisé au début, rangés dans un dossier maître nommé InterventionPro_Data.

🏷️ Organisation

Chaque dossier d'intervention se crée ainsi :
[Titre]_[DATE]_[HEURE]

🔒 Accès bloqué après inactivité ?

Si le téléphone "oublie" l'autorisation après quelques semaines, lancez simplement une photo ou une création : Android affichera une alerte pour que vous cliquiez sur "Autoriser" à nouveau.
